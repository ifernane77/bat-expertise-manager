
# Cahier des charges — Bat Expertise Manager

## 1. Contexte

Bat Expertise utilise Trello pour gérer ses dossiers
et OrganiLog pour les devis et la facturation.

## 2. Problématique

Comment centraliser les principales activités
de Bat Expertise dans une application web interne ?

## 3. Objectif

Développer un prototype simple permettant de :
- Consulter un tableau de bord
- Gérer des clients fictifs
- Créer et suivre des dossiers
- Consulter des devis et factures fictifs
- Suivre les entrées et sorties de matériel

## 4. Utilisateurs

- Responsable
- Secrétaire
- Employés

## 5. Technologies

- HTML5 : structure des pages
- CSS3 : mise en forme
- JavaScript : interactions

## 6. Contraintes

- Application adaptée au niveau BTS SIO SLAM
- Données entièrement fictives
- Interface simple et responsive
- Pas d'authentification réelle
- Pas de base de données dans la première version

## 7. Résultat attendu

Un prototype fonctionnel de tableau de bord
présentant les principales activités de l'entreprise.

## 8. Conception de l'interface

L'application utilise une interface simple.

### Menu de navigation
- Tableau de bord
- Clients
- Dossiers
- Devis
- Factures
- Matériel

### Tableau de bord
- Nombre total de dossiers
- Nombre de dossiers en cours
- Nombre de dossiers terminés
- Tableau des derniers dossiers

### Charte graphique
- Bleu marine
- Blanc
- Gris clair

### Organisation
- Menu vertical à gauche
- Contenu principal à droite
- Affichage adapté aux ordinateurs
- Adaptation mobile prévue
